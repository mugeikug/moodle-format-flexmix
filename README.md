# format_flexmix

Moodleのコースフォーマットプラグインです。「ウィークリー(週ごと)」「トピック」「規定日以外の回
(補講などの非定期回)」のセクションを、**1つのコースの中に混在**させられます。

標準の週次(Weekly)フォーマットは、各セクションの日付をセクションの並び順から自動計算しています。
そのため、途中に補講用のセクションを1つ挿入すると、それ以降の週の日付表示が全てズレてしまいます。
本プラグインでは、セクションごとに「種別(週 / トピック / 非定期回)」を明示的に設定でき、週の日付は
**その種別が「週」であるセクションだけを数えて**計算するため、間にトピックや非定期回のセクションを
挿入しても、後続の週の日付はズレません。

## 主な機能

- セクション編集パネル(セクション名の右にある編集メニューの「セクションを編集」)に、標準のセクション
  設定に加えて「セクションの種別」(週 / トピック / 非定期回)と「セクションの日付」の項目が追加されます。
- **週**: ウィークリーフォーマットと同様に日付が自動計算されます(「セクションの日付」で個別に上書き
  可能)。
- **トピック**: トピックフォーマットと同様、日付を持たず「トピック N」という既定名になります。
- **非定期回**: 通常の週次の流れに含まれない単発のセクションです。「セクションの日付」を設定すると
  既定のセクション名にその日付が表示されます。
- いずれの種別でも、コア標準の機能でセクション名を自由にリネームできます(リネームすると既定の
  自動生成名より優先されます)。

## 使い方

1. コース作成・編集画面の「コースフォーマット」で「ウィークリー・非定期回・トピック混在」を選択します
   (既存のウィークリーフォーマットのコースから移行することもできます)。
2. 通常どおりセクションを追加します。新しいセクションは既定で「週」種別になります。
3. トピックにしたい、または補講など任意日時にしたいセクションは、そのセクションの編集メニューから
   「セクションを編集」を開き、「セクションの種別」を変更します。
4. 非定期回として日付を表示したい場合は「セクションの日付」を設定します。トピック・非定期回セクションは
   セクション名を自分で付けることを想定しています。

## インストール

このディレクトリの内容を、Moodleの `course/format/flexmix/` にコピーまたはシンボリックリンクし、
サイト管理者としてサイトにログインしてプラグインのインストールを完了してください。

## 動作確認済み / 対象バージョン

`version.php` の `requires`/`supported` は Moodle 3.11〜4.1 系列を宣言しています。GitHub Actions
(`.github/workflows/ci.yml`)で `MOODLE_311_STABLE`・`MOODLE_401_STABLE` 双方に対してphplint /
phpcs / phpdoc / validate / savepoints / mustache / PHPUnit / Behat が通ることを継続的に確認して
います。加えて、実際のMoodle環境(Docker上のMoodle 4.1.12、および実サーバー上のMoodle)にインストール
してのコース作成・セクション編集・お知らせフォーラムの自動作成・表示スタイルまで手動確認済みです。

Moodle 4.0でコースフォーマットの基底クラス(`format_base` → `\core_courseformat\base`)と出力層が
大きく変わっているため、本プラグインは以下の方法で単一コードベースのまま両対応しています。

- `lib.php`: `class_alias()` で、実行時に存在する方の基底クラス(3.11の`format_base`、または
  4.0+の`\core_courseformat\base`)を共通名にエイリアスしてから継承。
- `renderer.php`(3.x用)/ `classes/output/renderer.php`(4.0+用): それぞれのバージョンでのみ
  読み込まれるよう作られており、片方は各バージョンで読み込まれず無害です。Moodle 4.0+では
  `format_section_renderer_base` が非推奨エイリアスになっているため、そのバージョンでは一切
  参照しないよう `\core_courseformat\base` の有無で切り分けています。
- `styles.css`: Boostテーマの `ul.topics`/`ul.weeks` 向けスタイル(黒丸の除去や余白)が
  `ul.flexmix` には適用されないため、同等のスタイルを同梱しています。
- `lang/*/format_flexmix.php`: コアが前提とする `hidefromothers`/`showfromothers` などの
  フォーマット別文字列(フォールバックが無く、未定義だと `[[hidefromothers]]` のようにそのまま
  表示されてしまう)を定義しています。

## 開発

```bash
composer create-project -n --no-dev --prefer-dist moodlehq/moodle-plugin-ci ci ^4
php ci/bin/moodle-plugin-ci install --plugin ./format_flexmix --db-host=127.0.0.1
php ci/bin/moodle-plugin-ci phpunit
php ci/bin/moodle-plugin-ci behat
```
